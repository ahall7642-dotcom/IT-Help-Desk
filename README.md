# IT Help Desk Ticketing System

## Project Overview
A web-based IT Help Desk Ticketing System that allows users to submit technical support requests and allows IT staff to manage and track tickets.

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Git and GitHub

## Features
- Submit IT support tickets
- Store tickets in a SQLite database
- View submitted tickets on a dashboard
- Update ticket status
- Track tickets as Open, In Progress, or Resolved

## What I Learned
- Building a web application with Python and Flask
- Connecting an application to a SQLite database
- Handling HTML form submissions
- Creating routes and displaying database records
- Using Git and GitHub for version control

## How to Run
1. Clone this repository.
2. Install Flask: `pip install flask`
3. Run the application: `python app.py`
4. Open `http://127.0.0.1:5000` in your browser.
